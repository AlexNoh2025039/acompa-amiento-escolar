Aviso de privacidad de Acompañamiento Escolar

Última actualización: 13 de noviembre de 2026

Este aviso explica cómo Acompañamiento Escolar trata la información personal cuando se usa la aplicación. Actualmente el proyecto está en etapa de pruebas y debe utilizarse únicamente con cuentas y datos ficticios. No ingreses información real de estudiantes mientras no exista autorización de la institución responsable para su uso.

Responsable y contacto

El responsable indicado para este proyecto es Xavier Lara, desarrollador de Acompañamiento Escolar. Para consultas sobre privacidad o solicitudes relacionadas con datos, escribe a xavierfernando.larabalcazar@gmail.com .

Información que puede tratar la aplicación

Según las funciones utilizadas, la aplicación puede tratar:

  • Datos de cuenta, como nombre, correo electrónico y credenciales de acceso. Las contraseñas se almacenan como hashes y no en texto legible.
  • Perfiles familiares y estudiantiles, como nombre, fecha de nacimiento, grado y materias.
  • Información educativa, como horarios, tareas, archivos adjuntos, prácticas, resultados y evaluaciones.
  • Mensajes y archivos que se proporcionen al tutor o a otras funciones de aprendizaje.
  • Datos técnicos necesarios para autenticar sesiones y proteger la aplicación.

Usos de la información

La información se utiliza para crear y proteger cuentas, organizar actividades escolares, ofrecer las funciones educativas solicitadas, mantener el servicio y enviar enlaces de restablecimiento de contraseña.

Servicios de terceros

  • Cuando se usan funciones de inteligencia artificial, el texto, contexto educativo y archivos necesarios para responder pueden enviarse a Google Gemini. Consulta la política de privacidad de Google .
  • Google Gmail API se utiliza para enviar mensajes de restablecimiento de contraseña al correo de la cuenta. El mensaje contiene el enlace temporal necesario para completar el cambio.
  • La aplicación utiliza servicios de alojamiento, una base de datos PostgreSQL y almacenamiento privado de archivos según la configuración del despliegue. Estos proveedores procesan información para operar el servicio.

La aplicación no vende información personal ni la utiliza para publicidad dirigida.

Conservación y eliminación

La información se conserva mientras sea necesaria para operar la cuenta y las funciones solicitadas. Al eliminar una cuenta familiar desde la aplicación, se eliminan sus registros relacionados y los archivos privados se envían a un proceso de borrado; algunos archivos pueden permanecer temporalmente pendientes de eliminación. Los enlaces de restablecimiento vencen a los 30 minutos y solo pueden utilizarse una vez.

Estudiantes menores de edad

Los perfiles de estudiantes deben ser gestionados por una persona adulta responsable o por una institución autorizada. Quien agregue información de un estudiante debe contar con la autorización necesaria. Durante la etapa actual de pruebas solo deben utilizarse datos ficticios.

Solicitudes y cambios a este aviso

Puedes escribir al correo de contacto para solicitar acceso, corrección o eliminación de información, o para consultar cómo se trata. Este aviso puede actualizarse cuando cambien las funciones o el uso del servicio; la fecha de actualización se indicará al inicio de la página.
